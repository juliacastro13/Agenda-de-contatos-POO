Agenda de Contatos — POO

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos (POO), utilizando a linguagem Java.

📌 Sobre o Projeto

A Agenda de Contatos é um sistema desenvolvido para cadastrar, consultar, editar e remover contatos.

O projeto será desenvolvido de forma incremental, recebendo novas funcionalidades e melhorias a cada versão.



🛠️ Tecnologias Utilizadas

* Java
* JDK
* IDE de desenvolvimento (Eclipse ou VS Code)
* Git e GitHub para controle de versões

⚙️ Funcionalidades

O sistema pode incluir funcionalidades como:

* Cadastrar contatos
* Listar contatos
* Buscar contatos
* Editar contatos
* Excluir contatos
* Organizar e gerenciar os dados dos contatos

🎯 Objetivo

O objetivo do projeto é colocar em prática os conceitos de Programação Orientada a Objetos, como:

* Classes e objetos
* Encapsulamento
* Métodos e atributos
* Construtores
* Herança
* Polimorfismo
* Organização do código

👨‍💻 Desenvolvimento

O projeto será atualizado ao longo da disciplina, com cada versão representando uma evolução do sistema.
